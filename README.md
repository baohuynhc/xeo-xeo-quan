# Xèo Xèo Quán — bản web

Chơi bánh xèo miền Tây trực tiếp trên trình duyệt.

Bản phát hành WebGL v39, lưu tiến trình trên trình duyệt của từng người chơi. Không đồng bộ với Facebook.

Kho này chỉ chứa bản game đã biên dịch và mã khởi động web. Các tài sản game thuộc dự án Xèo Xèo Quán; không cấp quyền tái phân phối hoặc sử dụng lại.
